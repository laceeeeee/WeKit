# 自定义消息气泡

> 自定义聊天中的消息气泡图片、颜色和圆角

## 类别

界面美化, 聊天

## 类型

可开关 & 可点击

## 描述

自定义聊天消息气泡的外观。支持为「自己的消息」和「对方的消息」分别设置:

- **文字颜色** — 浅色/深色模式下独立设置
- **气泡背景色** — 可设置纯色背景
- **气泡圆角** — 顶部滑块统一设置圆角半径 (0-32dp), 对方/自己消息同时生效
- **气泡图片** — 使用自定义 `.9.png` 图片替换气泡背景

支持的图片消息类型包括: 文本、链接、群通知、引用消息、音视频通话、语音消息。将图片文件放入 `<模块数据>/assets/` 目录, 命名为 `left_bubble.9.png` (对方气泡) 或 `right_bubble.9.png` (自己气泡) 即可生效。

## 使用方法

在模块设置中启用后, 点击配置颜色、圆角和气泡图片

### 圆角说明

- 对话框顶部的滑块可设置 0-32dp 的圆角半径, 对方/自己消息同时生效, 无独立设置
- 0 = 不自定义圆角 (使用微信默认气泡)
- 圆角启用后, 气泡背景将由纯色绘制 (不再使用 .9.png 拉伸效果); 此时若背景色留空, 会自动使用微信默认气泡颜色 (浅色/深色主题各自匹配)
- 圆角与气泡图片同时存在时, 气泡图片优先
